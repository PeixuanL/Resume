# 1.需求来源

## 1.1 来源产品规划

### 1.1.1 Inspector 8.1 现场离线执行能力建设

在设备机房、园区地下空间、弱网场景中，一线运维人员无法稳定访问在线服务，但仍需要继续查看工单、执行步骤、记录异常和现场资料，因此需要补齐运维助手端的工单离线模式能力。

## 1.2 来源项目

### 1.2.1 Inspector 8.1 运维助手现场执行专项

当前工单执行能力以在线为主，尚未形成项目级离线缓存、离线资源下载、离线执行、恢复联网同步、按项目清理缓存的完整闭环，需要通过本次 PRD 统一补齐。

# 2.产品功能价值

1. 保证一线人员在弱网或断网环境下仍可继续执行工单，降低现场作业中断风险。
2. 保证离线数据结构与在线数据结构一致，避免执行端逻辑因离线能力而分叉。
3. 保证离线执行后的结果、图片、视频、文本说明可在联网后完整回传，支持验收闭环。
4. 通过项目级缓存控制，降低用户理解成本，避免复杂缓存清理带来的误删风险。
5. 通过降级策略保证模板库、MR、附件等外围能力异常时，工单主执行链路仍可继续。

# 3.功能目标

- 功能目标1：实现运维助手端按项目下载并缓存工单执行所需的结构化数据和资源。
- 功能目标2：实现离线查看待办工单、进入工单执行页、完成列表步骤和流程图步骤执行。
- 功能目标3：实现离线情况下采集图片、视频、文本说明并本地暂存。
- 功能目标4：实现恢复联网后按固定顺序自动或手动同步离线结果。
- 功能目标5：实现按项目清理全部缓存，且不影响其他项目数据。

# 4.名词解释

| 名词 | 解释 |
|---|---|
| 离线模式 | 运维助手端在无网络或弱网情况下，依赖本地缓存完成工单查看与执行的运行模式 |
| 离线项目 | 当前已下载离线缓存的数据项目维度，用于缓存管理、执行隔离和缓存清理 |
| 结构化数据 | 工单主数据、设备快照、步骤快照、结果规则、消息摘要等体积较小但执行闭环必须的数据 |
| 资源数据 | 参考资料附件、3D演示剧本资源、缩略图、必要预览文件等较大体积资源 |
| 待同步数据 | 离线执行后尚未回传服务端的扫码结果、步骤结果、图片、视频、文本说明、提交动作等 |
| 项目缓存 | 以项目为边界存储在本地的结构化数据、资源数据和待同步数据 |
| 降级策略 | 某项资源或外围能力不可用时，系统对页面、入口或交互做出的降级处理，不阻断工单主流程 |

# 5.客户场景描述

## 5.1 场景描述

一线运维人员经常在地下机房、设备夹层、信号不稳定的现场执行工单。此类场景下，用户需要提前下载项目内待办工单数据和必要资源，在断网时仍能打开工单、查看步骤、填写异常、上传本地媒体，并在恢复联网后统一同步结果。

## 5.2 客户业务流程

1. 运维人员在有网环境下进入项目，下载该项目的离线数据包。
2. 系统缓存项目内待办工单、步骤、设备快照、参考资料索引、MR 元数据及必要资源。
3. 用户在无网环境下进入工单列表并执行工单。
4. 用户离线填写步骤结果、异常说明并上传现场图片/视频，结果暂存本地。
5. 网络恢复后，系统按固定顺序将本地数据同步回服务端。
6. 用户可按项目清理缓存，释放本地空间。

# 6.产品功能逻辑

1. 工单离线模式仅作用于 `运维助手端（iOS）`，业务监控端不提供离线能力。
2. 离线模式不改变工单状态机，仅改变数据来源和交互降级策略。
3. 项目是离线缓存的最小隔离单位；缓存下载、查看、同步、清理均以项目为边界。
4. 离线执行端只消费工单快照、设备快照、步骤快照和 MR 元数据快照，不实时依赖模板库、设备模块或告警模块。
5. 离线模式下，结构化数据缺失会阻断工单打开；资源缺失仅阻断对应增强能力，不阻断步骤主流程。
6. 本期只支持“按项目清理全部缓存”，不提供复杂分类清理。

# 10.功能详细描述

## 10.1 查看离线项目与缓存状态（iOS / 运维助手）

### 10.1.1 页面示意图

- 页面位置：运维助手端工单列表页顶部导航栏状态条
- 页面结构：顶部导航栏状态条 + 下载/同步/清理操作区

### 10.1.2 页面数据、操作及按钮说明

#### 10.1.2.1 操作说明

1. 用户进入运维助手端项目后，可在工单列表页顶部导航栏状态条查看当前项目的缓存状态。
2. 页面展示当前项目是否已下载结构化数据、资源数据以及是否存在待同步数据。
3. 页面需同时展示全局离线标识、当前项目待同步数量、资源是否已缓存等离线 UI 状态。
4. 用户可点击下载按钮下载当前项目的离线数据包。
5. 若当前项目已存在待同步数据，则页面需显著提示同步状态，并提供【手动同步】入口。
6. 用户可在同一状态区域触发“按项目清理全部缓存”操作。

#### 10.1.2.2 数据及按钮说明

| 序号 | 字段名称 | 字段类型 | 数据来源 | 是否必填 | 字段描述 | 备注 |
|---|---|---|---|---|---|---|
| 1 | 项目名称 | 文本 | 项目上下文 | 是 | 当前项目名称 | |
| 2 | 结构化数据状态 | 状态文本 | 本地缓存索引 | 是 | 已下载/未下载/下载中/下载失败 | |
| 3 | 资源数据状态 | 状态文本 | 本地缓存索引 | 否 | 已下载/部分下载/未下载 | 指参考资料、3D演示资源等 |
| 4 | 待同步数量 | 文本 | 本地待同步队列 | 否 | 当前项目待同步记录数量 | 大于 0 时高亮 |
| 5 | 上次同步时间 | 文本 | 本地同步日志 | 否 | 最近一次同步完成时间 | |
| 6 | 下载离线数据 | 按钮 | / | / | 下载当前项目结构化数据和资源索引 | 有网时可点 |
| 7 | 继续下载资源 | 按钮 | / | / | 补充下载参考资料和3D演示剧本资源 | 结构化数据已下载后显示 |
| 8 | 手动同步 | 按钮 | / | / | 手动触发待同步数据上报 | 仅有网且存在待同步数据时可点 |
| 9 | 清理缓存 | 按钮 | / | / | 打开按项目清理全部缓存确认弹窗 | |
| 10 | 全局离线标识 | 标签 | 系统网络状态+本地缓存状态 | 否 | 展示当前是否离线可执行、是否存在待同步数据 | 顶部导航栏展示 |
| 11 | 同步状态提示 | 标签/提示条 | 本地同步队列 | 否 | 展示同步中、同步失败、可手动同步等状态 | |

### 10.1.3 页面涉及角色及权限说明

具备 `运维助手-工单执行-查看` 权限的用户可查看当前项目离线状态；具备 `运维助手-工单执行-离线管理` 权限的用户可下载、同步和清理缓存。

### 10.1.4 异常情况处理方案

1. 当前无网络时，下载和手动同步按钮置灰并提示“当前网络不可用”。
2. 本地存储空间不足时，下载前提示用户清理空间。
3. 本地缓存索引损坏时，提示“缓存异常，请重新下载项目数据”。

## 10.2 下载工单离线数据包（iOS / 运维助手）

### 10.2.1 页面示意图

- 页面位置：工单列表页顶部导航栏状态条中的下载操作区
- 页面结构：下载确认弹窗 + 进度条 + 下载完成提示

### 10.2.2 页面数据、操作及按钮说明

#### 10.2.2.1 操作说明

1. 用户在有网环境下点击【下载离线数据】。
2. 系统下载当前项目下离线执行所需的结构化数据，包含：
   - 工单主数据
   - 工单设备快照
   - 工单步骤快照
   - 规则字段
   - 计划时间
   - 异常记录要求
   - 消息摘要或必要状态摘要
3. 下载完成后，项目状态更新为“结构化数据已下载”。
4. 若本次下载同时携带资源索引，则后续资源下载基于该索引继续进行。

#### 10.2.2.2 数据及按钮说明

| 序号 | 字段名称 | 字段类型 | 数据来源 | 是否必填 | 字段描述 | 备注 |
|---|---|---|---|---|---|---|
| 1 | 下载范围说明 | 文本 | 系统 | / | 说明本次下载包含的结构化数据范围 | |
| 2 | 下载进度 | 进度条 | 系统 | / | 展示当前下载进度 | |
| 3 | 取消下载 | 按钮 | / | / | 取消当前下载任务 | 取消后保留已完成部分索引或回滚，按实现定稿 |
| 4 | 下载完成 | 状态提示 | 系统 | / | 提示下载完成 | |

#### 10.2.2.3 数据范围限制

1. 仅下载当前项目下与当前用户相关、且符合离线策略的工单数据。
2. 未到计划开始时间的待执行工单是否预下载，默认按项目策略决定；首版建议随项目工单一并下载，执行列表仍按计划开始时间过滤展示。
3. 结构化数据是离线执行的刚需数据，下载失败则工单不可离线打开。

### 10.2.3 页面涉及角色及权限说明

具备 `运维助手-工单执行-离线管理` 权限的用户可下载项目离线数据包。

### 10.2.4 异常情况处理方案

1. 下载中断时，提示“下载中断，可重试继续下载”。
2. 接口异常时，提示“离线数据下载失败，请稍后重试”。
3. 若项目切换，则当前下载任务应终止并提示重新选择项目。

## 10.3 下载离线资源（iOS / 运维助手）

### 10.3.1 页面示意图

- 页面位置：工单列表页顶部导航栏状态条中的资源下载区
- 页面结构：资源摘要 + 下载状态 + 重试入口

### 10.3.2 页面数据、操作及按钮说明

#### 10.3.2.1 操作说明

1. 结构化数据下载完成后，用户可继续下载参考资料和3D演示剧本资源。
2. 资源下载按当前项目内工单步骤引用的资源索引执行。
3. 资源下载完成后，页面标记为“资源已下载”或“资源部分下载”。
4. 若仅结构化数据已下载、资源未下载，用户仍可离线执行工单，但无法离线查看缺失资源。

#### 10.3.2.2 数据及按钮说明

| 序号 | 字段名称 | 字段类型 | 数据来源 | 是否必填 | 字段描述 | 备注 |
|---|---|---|---|---|---|---|
| 1 | 参考资料状态 | 状态文本 | 本地缓存索引 | 否 | 已下载/部分下载/未下载 | |
| 2 | 剧本资源状态 | 状态文本 | 本地缓存索引 | 否 | 已下载/部分下载/未下载 | 剧本/MR能力关闭时隐藏 |
| 3 | 下载资源 | 按钮 | / | / | 下载当前项目资源 | |
| 4 | 重试下载 | 按钮 | / | / | 对失败资源重试下载 | |

#### 10.3.2.3 资源降级规则

1. 参考资料未下载时：
   - 步骤仍可执行
   - 参考资料缩略卡片或文件卡片点击后提示“当前资料未缓存，请联网后查看”
2. 3D演示剧本资源未下载时：
   - 步骤仍可执行
   - 3D演示入口点击后提示“当前剧本资源未缓存，请联网后下载”
3. 剧本/MR 能力关闭时，不展示剧本资源状态和入口。

### 10.3.3 页面涉及角色及权限说明

具备 `运维助手-工单执行-离线管理` 权限且项目启用对应能力的用户，可下载资源数据。

### 10.3.4 异常情况处理方案

1. 某项资源下载失败时，不影响结构化数据可用性。
2. 资源部分下载时，需在页面清晰展示“部分可离线使用”状态。

## 10.4 离线查看待办工单（iOS / 运维助手）

### 10.4.1 页面示意图

- 页面位置：运维助手工单执行首页
- 页面结构：待执行 / 执行中 / 已完成 三个主 Tab + 工单卡片列表

### 10.4.2 页面数据、操作及按钮说明

#### 10.4.2.1 操作说明

1. 当项目结构化数据已下载后，用户在无网状态下仍可打开工单列表。
2. 列表分组规则与在线一致：
   - `待执行`：真实状态为待执行且当前时间已达到计划开始时间
   - `执行中`：真实状态为执行中的工单，以及驳回后回到执行中的工单
   - `已完成`：真实状态为待验收和已关闭的工单
3. 挂起工单不进入运维助手主列表。

## 10.5 离线执行列表类工单（iOS / 运维助手）

### 10.5.1 页面示意图

- 页面位置：运维助手离线状态下的工单执行页
- 页面结构：工单基本信息区 + 通用步骤区（仅多设备工单时展示）+ 当前设备步骤区 + 结果录入区

### 10.5.2 页面数据、操作及按钮说明

#### 10.5.2.1 操作说明

1. 用户在离线状态打开列表类工单后，页面按本地步骤快照顺序展示步骤。
2. 若当前工单存在多设备通用步骤，则先执行通用步骤，再执行对应设备步骤。
3. 每条步骤的结果类型固定为 `正常 / 异常 / 不适用`。
4. 若步骤配置了 `必须记录项`，则结果为正常时需补录对应文本、图片或视频。
5. 若结果为 `异常`，除满足步骤配置的 `必须记录项` 外，系统默认还要求 `文字说明或现场图片二选一必填`。
6. 若结果为 `不适用`，则需填写不适用原因。
7. 结果填写后本地即时保存为待同步数据。

### 10.5.4 异常情况处理方案

1. 必做步骤未填写结果时，禁止提交整单。
2. 本地媒体写入失败时，提示用户重试或检查本地空间。
3. 当前工单在离线期间被服务端挂起，离线端无法立即感知；联网同步后应按服务端规则将该工单移出运维助手主待办列表，并返回状态冲突提示。

## 10.6 离线执行流程图类工单（iOS / 运维助手）

### 10.6.2 页面数据、操作及按钮说明

#### 10.6.2.1 操作说明

1. 流程图类工单离线执行时，页面只展示当前节点，不展示完整画布。

## 10.7 恢复联网后的同步上报（iOS / 运维助手）

### 10.7.1 页面示意图

- 页面位置：工单列表页顶部导航栏状态条与工单列表页的同步提示区域
- 页面结构：待同步摘要 + 同步进度 + 同步结果提示

### 10.7.2 页面数据、操作及按钮说明

#### 10.7.2.1 操作说明

1. 当系统检测到网络恢复且当前项目存在待同步数据时，展示同步提示。
2. 用户可手动点击【手动同步】，也可由系统自动触发同步；手动同步用于用户主动重试、查看同步队列和处理失败项。
3. 同步顺序固定为：
   - 步骤结果
   - 图片/视频等媒体
   - 工单汇总提交状态
   - 外接系统结果回填状态
4. 若同一工单同一步骤或同一提交对象存在并发离线提交，则以“先成功提交到服务端的版本”为准。
5. 后提交端收到冲突提示时，需展示：冲突对象、已生效提交时间、提交人、建议操作（刷新/重新填写/另存说明）。
6. 不允许静默覆盖已成功提交的数据。
7. 同步成功后，待同步数量清零，并更新上次同步时间。
8. 同步失败时，保留本地待同步数据，允许重试。

#### 10.7.2.2 数据及按钮说明

| 序号 | 字段名称 | 字段类型 | 数据来源 | 是否必填 | 字段描述 | 备注 |
|---|---|---|---|---|---|---|
| 1 | 待同步数量 | 文本 | 本地待同步队列 | 是 | 当前待同步记录数量 | |
| 2 | 手动同步 | 按钮 | / | / | 触发同步任务 | 有网时可点 |
| 3 | 同步进度 | 进度条/状态文本 | 系统 | / | 展示当前同步阶段 | |
| 4 | 同步成功提示 | 文本 | 系统 | / | 提示同步完成 | |
| 5 | 同步失败提示 | 文本 | 系统 | / | 提示失败原因 | 保留重试入口 |
| 6 | 冲突提示 | 弹窗/提示条 | 系统 | 否 | 展示冲突对象、已生效提交时间、提交人和建议处理动作 | 冲突时显示 |

### 10.7.3 页面涉及角色及权限说明

具备 `运维助手-工单执行-离线管理` 权限的用户可手动触发同步；无该权限时系统仅可自动同步。

### 10.7.4 异常情况处理方案

1. 若媒体上传失败，已成功上传的结构化数据不回滚，失败媒体保留待同步状态继续重传。
2. 若服务端返回工单状态冲突，需提示“工单状态已变化，请刷新后确认”，并保留本地原始记录供人工处理。
3. 若同一步骤已有其他终端先提交成功，则后提交端弹出冲突提示，不自动覆盖服务端结果。
4. 若外接系统结果回填失败，需保留本地失败记录并允许后续重试回填。
5. 若同步中断，任务应支持从上次失败阶段继续重试。

## 10.8 按项目清理全部缓存（iOS / 运维助手）

### 10.8.1 页面示意图

- 页面位置：工单列表页顶部导航栏状态条中的缓存管理入口
- 页面结构：确认弹窗

### 10.8.2 页面数据、操作及按钮说明

#### 10.8.2.1 操作说明

1. 用户点击【清理缓存】后，系统弹出二次确认弹窗。
2. 弹窗需明确提示：
   - 将清除当前项目的结构化数据
   - 将清除当前项目的参考资料和3D演示剧本资源
   - 将清除当前项目的待同步数据
   - 不影响其他项目缓存
3. 用户确认后，系统清理当前项目全部本地缓存。
4. 清理完成后，该项目需重新下载后才能再次离线使用。

#### 10.8.2.2 数据及按钮说明

| 序号 | 字段名称 | 字段类型 | 数据来源 | 是否必填 | 字段描述 | 备注 |
|---|---|---|---|---|---|---|
| 1 | 清理说明 | 文本 | 系统 | / | 说明清理范围和影响 | 二次确认必读 |
| 2 | 取消 | 按钮 | / | / | 关闭弹窗，不执行清理 | |
| 3 | 确认清理 | 按钮 | / | / | 清理当前项目全部缓存 | 高风险操作 |

### 10.8.3 页面涉及角色及权限说明

具备 `运维助手-工单执行-离线管理` 权限的用户可清理项目缓存。

### 10.8.4 异常情况处理方案

1. 若当前项目存在待同步数据，确认弹窗需再次强调“清理后待同步数据将丢失”。
2. 清理失败时，提示用户重试；若部分文件未删除，系统需自动修复索引状态，避免缓存状态错乱。

# 11.对其他产品的影响

## 11.1 工单管理模块

### 11.1.1 影响内容

离线模式直接消费工单管理模块输出的工单快照、设备快照和步骤快照。

### 11.1.2 需配合调整事项

1. 工单服务需提供适合离线下载的数据接口。
2. 工单执行结果上报接口需支持离线补传。
3. 外接工单若存在原系统结果回填要求，需提供离线后补偿回填接口。

## 11.2 MR 平台

### 11.2.1 影响内容

离线模式需要提前下载剧本资源，支持断网执行中的3D演示入口显示和降级处理。

### 11.2.2 需配合调整事项

1. 提供资源索引和资源下载能力。
2. 提供剧本资源是否可离线运行以及是否支持进入 MR 模式的能力标识。

## 11.3 附件服务

### 11.3.1 影响内容

离线执行需要本地保存图片、视频，并在联网后上传。

### 11.3.2 需配合调整事项

1. 附件服务需支持断点续传或失败重传。
2. 附件上传完成后需回写到执行记录。

## 11.4 平台底座

### 11.4.1 影响内容

离线模式需要依赖项目上下文、本地存储、附件协议、同步日志和消息能力。

### 11.4.2 需配合调整事项

1. 提供本地缓存管理能力。
2. 提供同步日志和错误日志能力。
