# 1.需求来源

## 1.1 来源产品规划

### 1.1.1 Inspector 8.1 标准 SOP 能力建设

为保证工单创建和现场执行标准化，需要建立独立的模板库模块，沉淀设备类型级 SOP 模板，并支持与3D演示剧本、工单执行形成稳定连接。

## 1.2 来源项目

### 1.2.1 Inspector 8.1 工单与模板引用专项

当前工单创建依赖人工录入步骤，标准 SOP 复用能力不足，需要通过模板库建立“标准模板 -> 工单引用 -> 执行”的标准化闭环；工单反向沉淀能力仅预留后续扩展说明，本期不上线。

# 2.产品功能价值

1. 为工单创建提供可复用的标准 SOP，减少重复配置。
2. 通过模板版本管理，保证工单引用稳定、历史工单不受模板升级影响。
3. 将3D演示剧本统一收口在模板层配置，避免临时工单直接绑定剧本，降低业务复杂度。
4. 预留工单经验沉淀为模板草稿的后续扩展位，本期不上线。
5. 通过设备类型绑定，保证模板与设备实例解耦，支持模块即插即用。

# 3.功能目标

- 功能目标1：实现业务监控端独立查看、创建、编辑、发布、停用模板。
- 功能目标2：实现模板只绑定设备类型，不绑定设备实例。
- 功能目标3：实现模板列表步骤与流程图步骤两种建模方式。
- 功能目标4：实现模板与3D演示剧本一对一绑定，并通过步骤范围控制3D演示使用位置。
- 功能目标5：实现工单引用模板只读取发布版本快照；工单反向沉淀能力预留，但不纳入本期范围。

# 4.名词解释

| 名词 | 解释 |
|---|---|
| 模板库 | 业务监控端的标准 SOP 管理模块，独立于工单管理模块存在 |
| SOP 模板 | 面向单一设备类型的标准步骤模板，可被工单按当前设备引用 |
| 发布版本 | 可被工单创建页引用的模板版本 |
| 草稿版本 | 模板编辑中的未发布版本，不允许被工单直接引用 |
| 模板停用 | 将模板从可引用范围中移除，但不影响已创建工单 |
| 设备类型 | 模板适用范围对象，模板只绑定设备类型，不绑定设备实例 |
| 模板步骤 | 模板中定义的列表步骤或流程图节点 |
| 剧本范围 | 当前模板步骤在模板绑定3D演示剧本中的场景范围 |
| 反向沉淀 | 从已完成工单中抽取可复用内容，生成模板草稿的预留能力，本期不上线 |
| Copy-on-write | 工单引用模板后生成工单私有快照，后续模板升级不影响已创建工单 |

# 5.客户场景描述

## 5.1 场景描述

业务监控人员需要对常见设备故障和维修作业沉淀标准模板，后续创建工单时按当前设备快速引用标准步骤，减少重复配置。现场执行过程中积累的新经验可在线下整理后回流到模板库中，形成可复用的 SOP 资产。

## 5.2 客户业务流程

1. 业务监控人员在模板库中创建模板基础信息，选择适用设备类型。
2. 若该模板需要3D演示，则在模板基本信息中绑定3D演示剧本。
3. 用户按列表或流程图方式配置模板步骤。
4. 用户发布模板，形成可引用版本。
5. 业务监控端在新建工单时，按当前设备引用模板。
6. 本期不提供工单直接沉淀模板入口；如需复用现场经验，由业务监控端线下整理后回写模板库。

# 6.产品功能逻辑

1. 模板库模块仅在 `业务监控端（PC）` 提供，不在运维助手端提供管理入口。
2. 模板库与工单管理模块解耦：
   - 工单只能查询模板发布版本
   - 工单不能直接读写模板草稿
3. 模板只绑定设备类型，不绑定设备实例。
4. 一个模板只允许绑定一个3D演示剧本。
5. 只有模板基本信息已绑定3D演示剧本时，步骤或节点编辑中才出现 `剧本范围` 字段。
6. 工单不直接配置 MR，只继承模板中的 `script_id + script_scope` 元数据快照。

# 10.功能详细描述

## 10.1 查看模板列表（PC / 业务监控）

### 10.1.1 页面示意图

- 页面位置：设备监控页下模板库模块列表页
- 页面结构：顶部筛选区 + 模板列表表格区 + 新建按钮

### 10.1.2 页面数据、操作及按钮说明

#### 10.1.2.1 操作说明

1. 具备模板库查看权限的用户进入模板库后，默认看到模板列表。
2. 页面支持按模板名称、模板类型、设备类型、发布状态进行筛选。
3. 用户可点击【新建模板】进入模板创建抽屉。
4. 用户可点击某一卡片查看模板详情；草稿模板可直接编辑，已发布模板进入基于当前版本新建草稿的编辑流程。
5. 工单创建页面调用的是模板发布版本，不直接复用模板列表页 UI。

#### 10.1.2.2 数据及按钮说明

| 序号  | 字段名称   | 字段类型 | 数据来源 | 是否必填 | 字段描述                    | 备注                              |
| --- | ------ | ---- | ---- | ---- | ----------------------- | ------------------------------- |

具备 `业务监控-模板库-查看` 权限的用户可查看模板列表；具备 `业务监控-模板库-创建/编辑` 权限的用户可新建和编辑模板。

### 10.1.4 异常情况处理方案

1. 模板服务不可用时，列表页显示加载失败并提供重试入口。
2. 无权限用户不显示新建和编辑入口。

## 10.2 创建模板及基础信息（PC / 业务监控）

### 10.2.1 页面示意图

- 页面位置：模板库列表页点击【新建模板】后打开的右侧抽屉
- 页面结构：基础信息区 + 步骤配置区 + 版本操作区

### 10.2.2 页面数据、操作及按钮说明

#### 10.2.2.1 操作说明

1. 用户点击【新建模板】后进入模板创建抽屉。
2. 用户先填写基础信息，再配置模板步骤。
3. 模板保存后默认为草稿版本，不自动发布。
4. 模板可填写 `适用场景`，用于检索、筛选和工单引用时辅助判断，不参与执行端步骤逻辑。
5. 模板基础信息中若未绑定3D演示剧本，则步骤编辑中不显示 `剧本范围` 配置项。

#### 10.2.2.2 数据及按钮说明

| 序号 | 字段名称 | 字段类型 | 数据来源 | 是否必填 | 字段描述 | 备注 |
|---|---|---|---|---|---|---|
| 1 | 模板名称 | 输入框 | 手动输入 | 是 | 模板名称 | 建议上限 100 字 |
| 2 | 模板类型 | 下拉框 | 字典 | 是 | 模板业务类型 | 与工单类型共用枚举：故障维修/巡检任务/点检任务/维护/临时工单 |
| 3 | 适用设备类型 | 选择器 | 设备类型服务 | 是 | 当前模板绑定的设备类型 | 不允许选择设备实例 |
| 4 | 适用场景 | 标签输入/多值选择 | 手动输入 | 否 | 描述模板适用业务场景 | 用于检索和引用判断 |
| 5 | 模板描述 | 多行输入框 | 手动输入 | 否 | 模板说明 | 建议上限 300 字 |
| 6 | 3D演示剧本 | 选择器 | MR 平台 | 否 | 当前模板绑定的3D演示剧本 | 仅允许 1 个 |
| 7 | 保存草稿 | 按钮 | / | / | 保存当前模板草稿 | 不发布 |
| 8 | 发布 | 按钮 | / | / | 发布当前模板版本 | 需校验完整性 |

#### 10.2.2.3 基础信息限制规则

1. 模板只绑定单一设备类型，不绑定设备实例。
2. 一个模板只能绑定一个3D演示剧本。
3. 模板创建时必须先选择设备类型，后续工单才能按设备类型查询模板。
4. 模板类型与工单类型共用同一套业务分类口径，用于工单引用筛选与模板检索；模板类型仅在模板侧使用，不参与执行态逻辑。
5. `适用场景` 仅用于模板描述、筛选和引用预览，不作为执行端状态或步骤分支条件。
6. 模板草稿可多次编辑；仅发布版本可供工单引用。

### 10.2.3 页面涉及角色及权限说明

具备 `业务监控-模板库-创建` 权限的用户可创建模板；具备 `业务监控-模板库-发布` 权限的用户可发布模板。

### 10.2.4 异常情况处理方案

1. 未选择适用设备类型时，禁止保存和发布。
2. 模板名称重复时，需按产品规则提示重名或允许同名不同版本，首版建议模板名称允许重复但需结合设备类型和版本区分。

## 10.3 绑定适用设备类型与3D演示剧本（PC / 业务监控）

### 10.3.1 页面示意图

- 页面位置：模板创建/编辑抽屉中的基础信息区

### 10.3.2 页面数据、操作及按钮说明

#### 10.3.2.1 操作说明

1. 用户在模板基本信息中选择 `适用设备类型`。
2. 若模板需要3D演示，则在同一区域选择 `3D演示剧本`。
3. 仅当3D演示剧本已选择成功后，步骤编辑区域才显示 `剧本范围` 字段。
4. 更换3D演示剧本会清空已有步骤中的 `剧本范围` 配置，并要求用户重新确认。

#### 10.3.2.2 数据及按钮说明

| 序号 | 字段名称 | 字段类型 | 数据来源 | 是否必填 | 字段描述 | 备注 |
|---|---|---|---|---|---|---|
| 1 | 适用设备类型 | 选择器 | 设备类型服务 | 是 | 当前模板适用设备类型 | 单选 |
| 2 | 3D演示剧本 | 选择器 | MR 平台 | 否 | 当前模板绑定剧本 | 单选 |
| 3 | 剧本范围 | 步骤字段 | 剧本元数据 | 否 | 当前步骤在剧本中的场景范围 | 仅在已绑定剧本时显示 |

#### 10.3.2.3 绑定限制规则

1. 模板与3D演示剧本为一对一关系。
2. 工单不允许直接配置剧本；只能在模板中绑定后被工单继承。
3. 删除剧本绑定后，当前模板中所有 `剧本范围` 配置失效并需清空。

### 10.3.3 页面涉及角色及权限说明

具备 `业务监控-模板库-编辑` 权限且项目启用剧本/MR能力的用户，可绑定3D演示剧本。

### 10.3.4 异常情况处理方案

1. MR 平台不可用时，3D演示剧本选择器置灰或隐藏，不影响模板本身保存。
2. 剧本范围在 MR 平台中已失效时，发布前需提示修正。

## 10.4 创建列表类模板步骤（PC / 业务监控）

### 10.4.1 页面示意图

- 页面位置：模板创建抽屉中的步骤配置区
- 页面结构：列表步骤表格 + 步骤编辑弹窗

### 10.4.2 页面数据、操作及按钮说明

#### 10.4.2.1 操作说明

1. 用户在步骤配置区选择 `列表` 模式后，按顺序新增模板步骤。

4. 若模板已绑定3D演示剧本，则每条步骤可选择对应的 `剧本范围`。

#### 10.4.2.2 数据及按钮说明

## 10.5 创建流程图类模板步骤（PC / 业务监控）

### 10.5.1 页面示意图

- 页面结构：流程图画布 + 节点编辑层

### 10.5.2 页面数据、操作及按钮说明

#### 10.5.2.1 操作说明

#### 10.5.2.3 流程图限制规则

1. 首版不支持并行、回环、子流程。
2. 判断节点最多 2 个分支。
3. 列表模式切换到流程图模式始终允许；流程图模式切回列表模式仅在无判断、无分支时允许。
4. 模板发布前必须保证流程从开始到结束完整闭环。
5. 模板侧本期不做扫码签到配置；扫码拉起任务仅作为工单执行侧 P2 预留能力。
6. 处理节点中的 `必须记录项` 语义与列表步骤一致，对正常与异常结果共用；异常场景统一按系统默认规则执行：`文字说明或现场图片二选一必填`；判断节点不配置通用结果类型，但可通过 `分支性质` 标记异常分支或不适用分支。

### 10.5.4 异常情况处理方案

1. 流程图未闭环、分支不完整、存在孤立节点时，禁止发布。
2. 含判断分支的流程图切回列表模式时，提示不支持转换。

## 10.6 模板发布与版本管理（PC / 业务监控）

### 10.6.1 页面示意图

- 页面位置：模板详情页的版本区和发布操作区

### 10.6.2 页面数据、操作及按钮说明

#### 10.6.2.1 操作说明

1. 模板初次保存后为草稿。
2. 用户点击【发布】后，当前草稿生成新发布版本。
3. 已发布模板再次编辑时，不直接修改历史发布版本，而是基于当前版本形成新草稿，发布后成为新版本。
4. 用户可在模板详情页点击【复制模板】，基于当前模板生成一份新的模板草稿。
5. 用户可在历史版本中点击【回滚】；回滚不会覆盖当前发布版，而是基于目标历史版本生成一份新的草稿。
6. 工单创建仅可查询 `已发布` 的模板版本。

#### 10.6.2.2 数据及按钮说明

| 序号 | 字段名称 | 字段类型 | 数据来源 | 是否必填 | 字段描述 | 备注 |
|---|---|---|---|---|---|---|
| 1 | 当前版本号 | 文本 | 模板服务 | 是 | 最新版本号 | |
| 2 | 发布状态 | 文本 | 模板服务 | 是 | 草稿/已发布/已停用 | |
| 3 | 版本列表 | 列表 | 模板服务 | 否 | 展示历史版本信息 | 只读 |
| 4 | 复制模板 | 按钮 | / | / | 基于当前模板生成新草稿 | 不复制历史版本和使用记录 |
| 5 | 发布 | 按钮 | / | / | 将当前草稿发布为新版本 | |
| 6 | 查看历史版本 | 按钮 | / | / | 查看指定历史版本详情 | 不可直接编辑 |
| 7 | 回滚 | 按钮 | / | / | 基于指定历史版本生成新草稿 | 不覆盖当前发布版 |

### 10.6.3 页面涉及角色及权限说明

具备 `业务监控-模板库-发布` 权限的用户可发布模板并查看版本。

### 10.6.4 异常情况处理方案

1. 发布校验未通过时，提示具体缺失项。
2. 复制模板失败时，不影响当前模板。
3. 回滚失败时，保持当前版本内容不变并提示重试。
4. 发布失败时保留当前草稿，不丢失已编辑内容。

## 10.8 工单引用模板（PC / 业务监控）

### 10.8.1 页面示意图

- 页面位置：工单创建抽屉中的 `选择模板` 弹窗

### 10.8.2 页面数据、操作及按钮说明

#### 10.8.2.1 操作说明

1. 在工单创建页，用户切换到某一设备后点击【选择模板】。
2. 系统按当前设备的设备类型查询可引用模板，并以表格展示 `名称 / 模板类型 / 适用场景 / 创建时间`。
3. 用户可通过关键字搜索过滤候选模板；`适用场景` 直接取模板 `适用场景` 字段，无数据时显示 `-`。
4. 用户可先点击【预览模板】查看只读模板内容；单选模板后点击【确认】，系统读取该模板的发布版本快照，生成当前设备的工单步骤快照。
5. 模板应用仅对当前设备生效，不影响其他设备和通用步骤。

#### 10.8.2.2 数据及按钮说明

| 序号 | 字段名称 | 字段类型 | 数据来源 | 是否必填 | 字段描述 | 备注 |
|---|---|---|---|---|---|---|
| 1 | 名称 | 表格字段 | 模板发布版本 | 是 | 模板名称 | |
| 2 | 模板类型 | 表格字段 | 模板发布版本 | 是 | 模板业务类型 | |
| 3 | 适用场景 | 表格字段 | 模板发布版本 | 否 | 直接展示模板 `适用场景` 字段 | 无数据时显示 `-` |
| 4 | 创建时间 | 表格字段 | 模板发布版本 | 是 | 模板创建时间 | |
| 5 | 搜索 | 输入框 | 手动输入 | 否 | 按模板名称等关键字过滤候选模板 | |
| 6 | 预览模板 | 按钮 | 模板发布版本 | 否 | 打开模板只读预览弹窗 | 不允许直接编辑模板 |
| 7 | 选择 | 单选 | 手动选择 | 是 | 单选一个模板作为当前设备步骤来源 | |`r`n| 8 | 确认 | 按钮 | / | / | 将模板快照写入当前设备步骤 | 仅对当前设备生效 |

#### 10.8.2.3 引用限制规则

1. 工单只能引用模板发布版本。
2. 工单引用后采用 copy-on-write 生成工单私有步骤快照。
3. 后续模板升级不影响已创建工单。
4. 若工单来自外接系统且步骤结构为只读快照，则默认关闭模板覆盖写入能力；如需使用模板，仅允许只读预览，不允许覆盖、追加、删除或重排外接步骤。

### 10.8.3 页面涉及角色及权限说明

具备 `业务监控-工单管理-创建` 权限且模板库模块启用时，用户可在工单创建页引用模板。

### 10.8.4 异常情况处理方案

1. 模板库模块关闭时，工单创建页隐藏【选择模板】入口。
2. 模板接口不可用时，不影响手动配置步骤。

## 10.9 工单反向沉淀模板草稿（PC / 业务监控）

### 10.9.1 页面示意图

- 页面位置：已完成工单详情页中的“存为模板”入口（本期不上线）

### 10.9.2 页面数据、操作及按钮说明

#### 10.9.2.1 操作说明

1. 本功能本期不上线，不纳入本期开发与验收范围；若后续启用，则由业务监控端在已完成工单详情点击【存为模板】。
2. 系统从工单中抽取可复用内容，生成模板草稿。
3. 反向沉淀只生成模板草稿，不直接发布。
4. 若源工单不是来自带 MR 的标准模板，则新模板草稿默认不带 MR 绑定；如需 MR，需在模板基础信息中手动绑定。

#### 10.9.2.2 数据及按钮说明

| 序号 | 字段名称 | 字段类型 | 数据来源 | 是否必填 | 字段描述 | 备注 |
|---|---|---|---|---|---|---|
| 1 | 存为模板 | 按钮 | / | / | 从当前工单生成模板草稿 | 本期不上线 |
| 2 | 模板草稿名称 | 输入框 | 手动输入/默认回填 | 是 | 新模板草稿名称 | 可默认回填工单名称 |
| 3 | 适用设备类型 | 选择器 | 工单设备快照/手动确认 | 是 | 模板适用设备类型 | 从工单设备类型推断 |

#### 10.9.2.3 沉淀内容与限制

1. 允许沉淀的内容：
   - 可复用的步骤名称、步骤描述、流程结构、参考资料、必须记录项与系统默认异常留痕要求
2. 不允许沉淀的内容：
   - 设备实例 ID
   - 负责人
   - 计划时间
   - 执行结果
   - 现场图片/视频
   - 验收记录
3. 工单沉淀不会反向更新原模板版本。

### 10.9.3 页面涉及角色及权限说明

具备 `业务监控-模板库-创建` 权限且具备 `业务监控-工单管理-查看` 权限的用户，可从工单详情发起沉淀模板草稿。

### 10.9.4 异常情况处理方案

1. 工单未关闭前不可沉淀模板。
2. 若工单中设备类型信息不完整，需提示用户补充后再沉淀。
