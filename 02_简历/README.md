# 02_简历

这里存放简历事实源、通用素材、岗位定制源稿、投递稿、历史稿和预览检查材料。

## 推荐使用顺序

1. 先看事实源：`00_通用素材库/00_事实源/李沛宣-背景信息汇总.md`
2. 再看表达素材：`00_通用素材库/01_表达素材/`
3. 根据岗位选择源稿：`02_岗位定制稿/`
4. 导出后放入：`03_当前投递/` 或对应岗位的 `输出PDF/`
5. 历史版本只查不改：`99_历史归档/`

## 目录说明

## 维护规则

- 修改任何简历前，先核对事实源，不新增未经确认的客户、指标、规模、职责或结果。
- 面试追问清单已移到 `../03_面试准备/00_通用答案库/`，简历区只保留简历相关材料。
- 浏览器 profile、Crashpad、临时渲染缓存不放在简历区，统一归档到 `../99_临时与归档/`。
- Word 另存网页产生的 `*_files/` 文件夹必须和对应 HTML 放在同一目录。
