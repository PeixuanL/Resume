# 职业规划工作台

> 这个文件夹用于长期沉淀职业规划、求职路径、阶段性决策和情绪/风险记录。
> 目标不是一次性找到完美答案，而是把模糊焦虑拆成可以观察、比较、执行和复盘的路线。

## 当前核心问题

- 长期担心：长期找不到工作。
- 当前迷茫：未来职业规划和发展方向不清晰。
- 主要吸引方向：外企、国际化岗位、远程工作、旅居办公。
- 主要现实顾虑：社保、税务/合规、薪资稳定性、远程岗位可信度、外企机会减少、自身能力匹配度。

## 当前暂定判断

现阶段不把“远程工作”作为唯一主线，而把它作为加分条件和探索支线。

更稳的主线是：外企/国际化 B2B AI 产品经理、数字孪生产品经理、工业 AI / IoT / 设施运维 / 企业 Agent 相关岗位。

短期策略是先降低“长期找不到工作”的概率，再逐步提高对远程、旅居、外企纯度的要求。

## 使用方式

每次讨论职业规划时，先更新一个问题：

> 我现在最想降低哪种不确定性？

然后只推进一个小块：方向判断、岗位池、简历策略、投递节奏、面试复盘、远程风险、生活方式预算，或能力补强。
