# JD 岗位筛选雷达

日期：2026-08-05

用途：以后看到岗位 JD 后，先用本表评估，再决定是否投递、是否定制简历、是否投入面试准备。避免被 JD 牵着走，也避免为了离开当前公司而进入新的消耗型环境。

## 1. 核心判断

当前求职不是在“留在烂公司”和“立刻进入理想外企”之间二选一，而是并行准备两条路径：

1. 外企直投：低频、高质量、认真定制。
2. 外企跳板：中频筛选，目标是补真实上线、用户反馈、产品方法论和可迁移作品。

第一跳不要求完美，但必须能服务第二跳。

## 2. 评分表

每个 JD 满分 30 分。

| 维度 | 评估问题 | 分数 |
|---|---|---|
| 方向相关 | 是否靠近 B2B / 工业 / 建筑 / 空间 / AI 应用 / 工作流 | 0-5 |
| 产品含量 | 是否真的做需求、原型、上线、迭代，而不是纯交付或纯售前 | 0-5 |
| 用户反馈 | 是否能接触真实用户、客户、数据或上线反馈 | 0-5 |
| 团队质量 | 是否有清晰流程、靠谱上级、稳定方向、基本产品方法 | 0-5 |
| 跳板价值 | 是否有英文、外企客户、行业品牌、作品沉淀、方法论迁移 | 0-5 |
| 风险成本 | 欠薪、混乱、加班、职责不清、纯执行消耗是否可控 | 0-5 |

## 3. 分类规则

```text
24-30：梦想岗，认真准备，定制简历和面试材料
18-23：跳板岗，可以投，重点判断上级和真实工作内容
14-17：保底但谨慎，除非现金流/离职压力很大
13 以下：不去
```

一票否决：

```text
欠薪风险
严重管理混乱
长期无明确产品线
纯 PPT 售前或纯项目交付
无法接触真实用户/客户反馈
岗位 title 是产品，但实际是销售、交付、杂活
```

## 5. 外企跳板岗位画像

可以考虑：

- 民企出海 B2B SaaS。
- 工业软件 / 低代码 / 数据平台 / 物联网平台。
- AI 应用公司，但不是纯模型平台。
- 智能硬件的软件产品团队。
- 有外企客户或英文交付环境的解决方案产品岗。
- 能做流程、原型、需求、上线和复盘的客户型 PM。

必须满足：

```text
不欠薪
有明确产品线
有真实用户或客户反馈
不是纯写 PPT 售前
能做原型 / 流程 / 需求 / 上线
老板或团队至少有基本产品方法
```
