# 万联易达集团 · 园区版产品经理面试准备

岗位：园区版产品经理 J14379
地点：北京朝阳区望京
薪资：20-40K
年限：5-10 年
学历：本科
准备日期：2026-07-26

## 使用顺序

1. 先读 `01_JD拆解与匹配策略.md`，确认这轮面试到底在考什么。
2. 面试前 30 分钟读 `02_面试总纲_开场与项目主线.md`，背自我介绍、主项目和岗位迁移。
3. 追问练习读 `03_高频问答_追问防守包.md`，重点练园区三端、AI 企服、数据驾驶舱、半定制落地。
4. 如果园区业务名词记不住，读 `05_园区业务概念白话速记.md`，先用白话理解政策计算器、AI 企业参谋、产业链图谱和监管驾驶舱。
5. 打开 `interactive-prep/index.html` 进行网页练习：左侧选题，中间看短答/完整/追问/边界，右侧可以改写并保存到浏览器。
6. 固定答案入口是 `final-answers.md`。其中已确认答案优先复用，JD 定制答案仍标为 draft，需要你面试前口述确认。
7. 原始 JD 截图文字整理在 `00_岗位JD_截图转写.md`。

## 这次岗位的一句话定位

这个岗位不是单纯做园区门户，也不是单纯做 AI 工具，而是要把管委会、入驻企业、本地服务商、产业链资源、政策/补贴、招商、数据监管和 AI 企业服务串成一个可落地的产业服务平台。

你的主线应是：

> 我做过复杂 B 端场景的产品化：把分散的数据、角色、流程和 AI 能力组织成可验证、可交付、可复制的业务闭环。园区平台对我来说是新行业，但底层产品能力和我在设施运维 Agent、数字孪生、数据接入与标品化交付中的经验高度相通。
