## 使用原则

- 简历、面试答案、作品集表达都优先引用 `02_简历/00_通用素材库/00_事实源/李沛宣-背景信息汇总.md` 和 `05_项目证据库/` 中的真实材料。
- 公司面试复盘跟随对应公司岗位包存放，不单独散在根目录。
- 学习材料放在 `06_学习与能力补强/`；只有已经可直接用于回答的问题，才进入 `03_面试准备/00_通用答案库/`。
- `05_输出PDF_待归并`、`99_旧入口与待归并`、`99_临时与归档` 是缓冲区，后续确认无用后再清理。

## 命名约定

- 公司面试包：`YYYY-MM-DD_公司_岗位_轮次`
- 简历草稿：`李沛宣_岗位_简历_单页或两页_版本说明.html`
- 投递 PDF：`李沛宣_岗位_简历_日期或版本.pdf`
- Word 另存网页时生成的 `*_files/` 目录必须与对应 HTML 放在同一文件夹内。
